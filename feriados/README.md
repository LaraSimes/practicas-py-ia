# Feriados de Argentina

Script que consulta la API de [ArgentinaDatos](https://argentinadatos.com) e informa cuántos feriados quedan en el año, cuál es el próximo y exporta la lista a CSV.

## Cómo correrlo

Desde la raíz del repo, con el entorno virtual activo:

```bash
python feriados/feriados.py
```
